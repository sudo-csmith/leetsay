# Contributing

Thank you for wanting to help with leetsay.

## What is welcome right now

- **Bug reports:** [open a bug report](https://github.com/sudo-csmith/leetsay/issues/new?template=bug_report.yml).
  Say what you did, what you expected and what happened. A pasted log
  helps: it never contains your words or the names of the programs you use.
- **Ideas:** [suggest something](https://github.com/sudo-csmith/leetsay/issues/new?template=feature_request.yml).
- **Security problems:** report them privately, never in a public issue. See
  [SECURITY.md](SECURITY.md).

## Code changes

Pull requests are not accepted for now. leetsay is maintained by one person,
and every release is built and signed from this repository, so all code
changes are made here. If you have a fix in mind, describe it in a bug report
or an idea; it may be taken up.

## What leetsay will stay

Ideas are weighed against the project's promises:

- Offline by default: nothing goes online without the user agreeing first.
- No accounts, statistics or tracking; audio is never saved.
- Lightweight and quick to start.
- Its own design: nothing copied from other apps.

## Conduct

Everyone taking part is expected to follow the
[Code of conduct](CODE_OF_CONDUCT.md).
